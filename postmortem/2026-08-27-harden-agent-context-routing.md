# Harden agent context routing

## Decision

Route every repository Skill through the same root-plus-nearest-local Context Pointer union used by ordinary implementation. Skills describe procedure only; they do not preload broad Guide owners or create a second documentation authority.

Record the selected authority in a lightweight active-plan Context Set keyed by repository-relative `path[#anchor]@content-sha`. Reuse unchanged entries, reroute only when scope, action branches, or content change, and pass the ledger rather than the full discovery transcript to later agents.

Replace broad reads of large conditional owners with action-specific Markdown anchors. Add representative routed-context byte ceilings and enforce them, Skill protocol adoption, and anchored routing for every conditional owner at or above 7,500 bytes through `just architecture`.

## Why

The first progressive-disclosure migration reduced standing briefs but still left three failure modes: optional Skills could unconditionally reload large documents, a new agent had no durable record of what had already been selected, and one broad Pointer could load an entire large owner for a narrow change.

A Context Set preserves identity and freshness without copying owner prose. Anchored Pointers reduce the conditional payload while keeping the canonical owner intact. Scenario budgets measure the real routed union rather than only standing files, and the executable check prevents future Skills or briefs from silently returning to broad reads. Discovering large owners by size also prevents a growing Guide chapter from bypassing a stale hard-coded list.

## Gate change

Before this change, `just architecture` proved workspace dependency direction, forbidden inward framework dependencies, and the top-level multi-workflow threshold.

After this change it retains those proofs and additionally checks that every repository Skill uses Context Pointers and a Context Set, that every conditional owner at or above 7,500 bytes is referenced only through an anchor from standing briefs and Skills, and that representative routed-context scenarios remain below their declared byte ceilings. The new checks inspect governance text only and do not claim to judge semantic DDD ownership or model behavior.
